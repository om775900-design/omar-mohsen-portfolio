# Omar Mohsen — Social Video Editing Portfolio

This is a starter portfolio for an aspiring short-form video editor using Adobe Premiere Pro.

## Files
- `index.html`
<link rel="stylesheet" href="style.css">
— website content and project cards
- `style.css` — design and responsive layout
- `script.js` — updates the copyright year
- `PRACTICE_PROJECTS.md` — three practice briefs to help you create real portfolio pieces

## Preview
Extract the ZIP and open `index.html` in a browser. Internet is needed for the Google Fonts import; the site still works without it.

## Important before sharing
- The project cards are labeled as concepts. They are not actual client work or playable videos.
- Change `YOUR_EMAIL@example.com` in `index.html` to your actual email.
- Replace the LinkedIn URL with your own profile, or remove that button.
- When you finish an edit, upload it to YouTube (unlisted), Vimeo, or another reliable host and link the project card to the video.
- Don't claim client results or experience you don't have yet.

## Publish free with GitHub Pages
1. Create/sign in to GitHub.
2. Create a public repository such as `omar-mohsen-portfolio`.
3. Upload all files and the `assets` folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
6. Wait for GitHub to show the published site URL in the Pages section.
